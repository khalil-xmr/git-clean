# git-clean

An agent skill and Git hook that keeps repositories free of AI signatures, trailers, and boilerplate.

## Why

Many AI coding tools inject unwanted metadata into Git repositories:
- `Co-Authored-By: Claude...` or `Generated by AI` commit trailers.
- Agent directive files tracked in the repository root (`CLAUDE.md`, `.cursorrules`, prompt dumps).
- Conversational commit messages (*"I have updated..."*, *"Here is a summary..."*).
- Pull request descriptions filled with template headers and emojis.

## Rules

1. **No attribution**: Bans `Co-Authored-By`, `Claude-Session`, "Generated with", and assistant references in commits, PRs, issues, release notes, and code comments.
2. **No agent files**: Prevents tracking configuration files like `CLAUDE.md`, `.cursorrules`, or prompt dumps.
3. **No conversational text**: Strips pleasantries, intros, apologies, and recaps.
4. **No template decorations**: Eliminates emojis, shields.io badges, and decorative blockquotes.
5. **Standard commits**: Imperative subject under 50 characters, optional factual bullet points for the body, and matching existing repo conventions.
6. **Local identity**: Author and committer must reflect the user's local Git configuration, never an assistant or bot identity.

## Gates

- **Pre-commit**: Checks the message against the rules before running `git commit`.
- **Pre-push / Pre-release**: Verifies the payload before sending data to GitHub or Gitea.
- **Post-commit assertion**: Runs `git log -1 --pretty=fuller` after every commit to verify that no trailer was injected by the environment.

## Examples

### Commit Message

**Without git-clean:**
```text
I have updated the authentication logic to fix the timeout issue

* Fixed socket timeout
* Added error handling

Co-Authored-By: Claude <noreply@anthropic.com>
```

**With git-clean:**
```text
Fix auth timeout on stale socket connections

* Increase keep-alive timeout from 5s to 15s.
* Return 408 on socket deadline expiration.
```

## Installation

### Claude Code
```bash
mkdir -p ~/.claude/skills/git-clean
curl -fsSL -o ~/.claude/skills/git-clean/SKILL.md https://raw.githubusercontent.com/khalil-xmr/git-clean/main/SKILL.md
```

### Antigravity / Gemini CLI
```bash
mkdir -p ~/.gemini/config/skills/git-clean
curl -fsSL -o ~/.gemini/config/skills/git-clean/SKILL.md https://raw.githubusercontent.com/khalil-xmr/git-clean/main/SKILL.md
```

### Cursor
```bash
mkdir -p .cursor/rules
curl -fsSL -o .cursor/rules/git-clean.mdc https://raw.githubusercontent.com/khalil-xmr/git-clean/main/SKILL.md
```

### Native Git Hook (Standalone)
Enforce the rule at the repository level without an agent:
```bash
mkdir -p .git/hooks
curl -fsSL -o .git/hooks/commit-msg https://raw.githubusercontent.com/khalil-xmr/git-clean/main/hooks/commit-msg
chmod +x .git/hooks/commit-msg
```
